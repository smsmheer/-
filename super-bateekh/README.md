# سوبر بطيخ 🍉 (Super Bateekh)

لعبة منصات 2D كوميدية بأجواء حارة مصرية وقت المغربية.

## شغّلها فورًا (من غير تثبيت)
افتح `www/index.html` في متصفح الموبايل (أو الكمبيوتر). اضغط «إضافة للشاشة الرئيسية» وتشتغل كأنها تطبيق.

## اعمل APK وتثبّته على الموبايل (مجانًا، من غير برامج على جهازك)
1. اعمل حساب على github.com (مجاني) وأنشئ مستودع جديد (Repo) اسمه مثلًا `super-bateekh`.
2. ارفع محتويات المجلد ده للمستودع (من موقع GitHub: Add file → Upload files).
3. افتح تبويب **Actions** في المستودع — هتلاقي workflow اسمه build-apk شغال لوحده.
4. بعد ما يخلص (~5 دقائق)، افتح آخر run ونزّل ملف **super-bateekh-apk** (اسمه app-debug.apk).
5. انقل الـ APK للموبايل وثبّته (اسمح بالتثبيت من مصادر غير معروفة لما يطلب).

## التحكم
- اضغط في أي مكان للنط (نطتين مع الفراولة 🍓).
- زر 🍅 (الطماطم): رمي البذور. زر ⚡ (الخيار): النيترو.
- كيبورد: مسافة/سهم فوق = نط، F = رمي، N = نيترو.

## فتح الشخصيات
اجمع أطباق الجبنة القريش 🧀 وافتح من «شخصيات الحارة»:
الفراولة 15 🧀 | المانجو 30 🧀 | الخيار 50 🧀 | الطماطم 75 🧀
